# Image organization

Add new photos here as the redesign grows.

Recommended folders:
- `images/gallery/`
- `images/residential/`
- `images/commercial/`
- `images/solar/`
- `images/brand/`

Use descriptive filenames such as `westport-residential-exterior-01.jpg` rather than `IMG_1234.jpg`. Once photos are added, the site can reuse the strongest images across the Gallery and individual service pages.
